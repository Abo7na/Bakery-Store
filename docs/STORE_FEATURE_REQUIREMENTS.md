# متطلبات متجر مخبوزات الشام

هذا الملف هو المرجع الأساسي لقائمة ميزات المتجر المعتمدة أثناء المراجعة.
يجب الرجوع إليه قبل التنفيذ وبعد كل مرحلة، وتحديثه عند اعتماد ميزات جديدة.
لا تُعتبر أي ميزة منفذة لمجرد ورودها هنا؛ هذا الملف يوثق المتطلبات والاعتمادات فقط.

## 1. واجهة الزبون

### 1.1 الصفحة الرئيسية
- [x] البحث عن المنتجات.
- [x] العروض والخصومات.
- [x] حالة المخبز وساعات العمل.
- [x] التواصل مع المخبز.

### 1.2 المنتجات
- [x] عرض تفاصيل المنتج.
- [x] خيارات الحجم والإضافات.
- [x] إظهار السعر بعد الخصم.
- [x] تقييمات الزبائن.

### 1.3 سلة المشتريات
- [ ] لم تُعتمد ميزات إضافية محددة لهذا القسم حتى الآن.
- [ ] الاحتفاظ بالميزات الموجودة حالياً ومراجعتها عند تدقيق قسم السلة.

### 1.4 الطلبات وإتمام الطلب
- [x] جعل العنوان مطلوباً عند اختيار التوصيل فقط، واختيارياً عند الاستلام من المخبز.

- [x] سجل الطلبات السابقة.
- [x] إعادة الطلب السابق.
- [x] إلغاء الطلب وفق شروط وسياسة واضحة.

- [x] كوبونات الخصم.
- [x] مشاركة المنتجات.

## 2. مراجعة لوحة الإدارة
لم تبدأ مراجعة أقسام لوحة الإدارة بعد. ستضاف هنا الأقسام والميزات بعد مناقشتها واعتمادها واحداً تلو الآخر.

## 3. حالة التنفيذ
- حالة هذا المستند: توثيق المتطلبات المعتمدة فقط.
- حالة تنفيذ ميزات واجهة الزبون: لم يبدأ التنفيذ بناءً على هذه القائمة.
- حالة مراجعة لوحة الإدارة: لم تبدأ.
- لا تُغيّر الشيفرة أو البيانات قبل اكتمال مراجعة الصفحات واعتماد خطة التنفيذ صراحةً.
