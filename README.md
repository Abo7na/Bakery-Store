# مخبوزات الشام

متجر معجنات عربي باتجاه RTL، منشور كملفات ثابتة على Cloudflare Pages.

## هيكلية المشروع

- `index.html`: واجهة الزبون.
- `components/`: أجزاء المتجر المشتركة، السلة، إتمام الطلب، والتنقل الإداري.
- `admin/`: صفحات لوحة الإدارة:
  - `index.html`: النظرة العامة.
  - `products.html`: إدارة المنتجات.
  - `orders.html`: الطلبات ومراحل تنفيذها.
  - `sales.html`: البيع المباشر وفواتيره.
  - `inventory.html`: المواد الأولية والتوريد والسحب والتسويات.
  - `material-movements.html`: صفحة مستقلة لتقارير حركات مادة محددة.
  - `suppliers.html`: الموردون والمشتريات والدفعات والديون والمرتجعات والتقارير.
  - `settings.html`: إعدادات المتجر.
- `css/`: التنسيق العام، مع ملفات مستقلة لكل قسم إداري وملف `section-system.css` للعناصر المشتركة.
- `js/`: منطق المتجر ولوحة الإدارة، مقسّم حسب الوظيفة والصفحة.
- `js/vendor/xlsx.bundle.js`: مكتبة إنشاء ملفات Excel المستخدمة في تقارير الموردين والمخزون.
- `assets/`: صور SVG المحلية.
- `migrations/`: بداية مخطط قاعدة بيانات مستقبلي، وليست ربطاً فعالاً حالياً.

## ملفات JavaScript الرئيسية

### المتجر
- `js/core.js`: الحالة والتخزين والدوال المشتركة.
- `js/products.js`: عرض المنتجات.
- `js/cart.js`: السلة وملخص الطلب.
- `js/checkout.js`: التحقق وإرسال الطلب محلياً.
- `components-loader.js`: تحميل أجزاء واجهة المتجر.

### لوحة الإدارة
- `js/admin/navigation.js`: القائمة الجانبية.
- `js/admin/dashboard.js`: المؤشرات والمخطط وأحدث الطلبات.
- `js/admin/products.js`: إدارة المنتجات.
- `js/admin/orders.js`: إدارة الطلبات ومراحلها وخصم مخزون المنتجات.
- `js/admin/sales.js`: البيع المباشر وسجل الفواتير والطباعة.
- `js/admin/inventory.js`: المواد الأولية وحركاتها وتقارير المخزون وتصديره.
- `js/admin/material-movements.js`: تقارير مادة واحدة.
- `js/admin/suppliers.js`: الموردون والمشتريات والدفعات والمرتجعات وكشوف الحساب والتصدير.
- `js/admin/settings.js`: إعدادات المتجر.

## تجربة الاستخدام

- أقسام الإدارة صفحات مستقلة بعناوين URL واضحة.
- تصميم التبويبات والفلاتر والبطاقات يستند إلى مساحة الموردين وتقاريرها، مع تكييفه حسب وظيفة القسم.
- لا يظهر زر تصدير/طباعة عام في الأقسام التي لا تحتاجه؛ البيع المباشر يحتفظ بطباعة الفاتورة.
- تقارير الموردين والمخزون تدعم Excel والطباعة، ويمكن حفظ PDF من نافذة الطباعة.

## حالة التخزين والأمان — مهم

**النسخة الحالية تجريبية وتعتمد على `localStorage` في المتصفح.** هذا يعني:
- البيانات لا تتشارك تلقائياً بين هاتف المدير وأجهزة الزبائن أو بين متصفحات مختلفة.
- مسح بيانات المتصفح قد يؤدي إلى فقدان السجلات المحلية.
- صفحات الإدارة لا تحتوي حالياً على تسجيل دخول أو صلاحيات خادمية.
- لا تستخدم النسخة الحالية لإدارة متجر فعلي متعدد الأجهزة أو لاستقبال طلبات حقيقية قبل بناء API وقاعدة بيانات ومصادقة آمنة.

ملف `migrations/0001_initial.sql` بداية أولية فقط، ولا يغطي جميع بيانات التطبيق الحالية مثل الموردين وحركات المواد وفواتير البيع. كما أن مسارات Cloudflare Functions المشار إليها في وثيقة الإعداد لم تُنشأ بعد. راجع `CLOUDFLARE_SETUP.md` قبل أي محاولة ربط إنتاجية.

## التحقق

لا يحتوي المستودع حالياً على حزمة اختبارات آلية أو إعداد بناء. تم إجراء فحوصات ساكنة لسلامة صياغة JavaScript وتطابق عناصر الصفحات مع محددات السكربت، لكن ذلك لا يغني عن اختبار المتصفح وسيناريوهات الحساب الفعلية.
