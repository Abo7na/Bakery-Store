# مخبوزات الشام

متجر معجنات عربي (RTL) منشور كملفات ثابتة على Cloudflare Pages.

## بنية المشروع

- `index.html`: هيكل الصفحة الأساسي وروابط ملفات CSS.
- `components/`: أجزاء HTML مستقلة للرأس والواجهة والمنتجات ولوحة الإدارة والسلة وعناصر الهاتف والتذييل.
- `components-loader.js`: يحمل أجزاء HTML ثم يشغّل ملفات JavaScript بالترتيب.
- `css/`: ملفات التصميم الأساسية، مكونات الواجهة، والتصميم المتجاوب.
- `js/`: منطق البيانات، المنتجات، السلة، الدفع، الإدارة، وبدء التطبيق.
- `assets/`: الصور المحلية للمنتجات.

## ترتيب تشغيل JavaScript

1. `js/core.js`
2. `js/products.js`
3. `js/cart.js`
4. `js/checkout.js`
5. `js/admin.js`
6. `js/app.js`

يجب تحميل الأجزاء بهذا الترتيب لأن ملفات الوظائف تشترك في حالة المتجر والدوال الأساسية المعرفة في `core.js`.

## ملاحظة تشغيل

يجب تشغيل المشروع عبر خادم HTTP مثل Cloudflare Pages، وليس بفتح `index.html` مباشرة من نظام الملفات، لأن أجزاء HTML تُحمّل باستخدام `fetch`.

البيانات ما زالت محلية في المتصفح عبر `localStorage`، ولم يتم ربط قاعدة بيانات مشتركة بعد.
