# مخبوزات الشام

متجر معجنات عربي (RTL) منشور كملفات ثابتة على Cloudflare Pages.

## هيكلية المشروع

- `index.html`: واجهة الزبون الرئيسية.
- `components/`: أجزاء واجهة الزبون المشتركة، والسلة، والتنقل، والشريط الجانبي للإدارة.
- `admin/`: صفحات مستقلة للوحة الإدارة:
  - `index.html`: نظرة عامة.
  - `products.html`: إدارة المنتجات.
  - `orders.html`: إدارة الطلبات.
  - `settings.html`: إعدادات المتجر.
- `css/`: التنسيق العام والمتجر، مع `css/admin/` لتنسيقات الإدارة وصفحاتها.
- `js/`: وظائف المتجر والسلة والدفع، مع `js/admin/` لوظائف كل صفحة إدارية على حدة.
- `assets/`: الصور المحلية.
- `migrations/`: ملفات تهيئة قاعدة البيانات المستقبلية.

## تقسيم JavaScript

### واجهة الزبون
1. `js/core.js`: التخزين المحلي والدوال المشتركة.
2. `js/products.js`: عرض المنتجات والتصنيفات.
3. `js/cart.js`: السلة.
4. `js/checkout.js`: إتمام الطلب والدفع.
5. `js/app.js`: تشغيل الواجهة.

### لوحة الإدارة
- `js/admin/navigation.js`: تحميل القائمة الجانبية المشتركة وتحديد الصفحة الحالية.
- `js/admin/dashboard.js`: إحصاءات لوحة التحكم.
- `js/admin/products.js`: إضافة وتعديل وحذف المنتجات.
- `js/admin/orders.js`: البحث والفلترة وإدارة حالات الطلبات.
- `js/admin/settings.js`: إعدادات المتجر.

## قرار تجربة الاستخدام

واجهة الزبون تبقى متجراً واحداً: يتصفح المنتجات ثم يفتح السلة وإتمام الطلب دون مغادرة تجربة التسوق. أما لوحة الإدارة فكل قسم فيها صفحة مستقلة بعنوان URL خاص، لتسهيل الصيانة والتطوير.

## التشغيل والبيانات

يجب تشغيل المشروع عبر خادم HTTP مثل Cloudflare Pages، وليس بفتح ملفات HTML مباشرة، لأن أجزاء الواجهة المشتركة تُحمّل باستخدام `fetch`.

**تنبيه:** البيانات ما زالت محفوظة في `localStorage` على المتصفح الحالي. لا توجد حتى الآن قاعدة بيانات مشتركة أو تسجيل دخول آمن للمدير؛ لذلك لا تستخدم النسخة الحالية لاستقبال طلبات حقيقية من أجهزة متعددة.
